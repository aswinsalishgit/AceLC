Solution Upload Behaviour

How AceLC handles uploading accepted LeetCode solutions to your repository.

  • Each solution is placed in a folder named NNNN-Problem-Title (e.g. 0001-Two-Sum).
  • Two files are created per problem: SOLUTION.java (source code) and PROBLEM.md (full problem statement).
  • Commit messages include actual LeetCode runtime, memory, and Beats percentiles.
  • If a file already exists you will be prompted to overwrite or skip.
  • The repository README.md dashboard is automatically created or updated after every upload.

About AceLC

AceLC is an open-source tool developed under CodeGab to automatically upload accepted LeetCode solutions directly to your GitHub repository.
